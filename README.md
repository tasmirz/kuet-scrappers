# KUET Scrappers

> An initiative to collect and expose APIs for information from the KUET website and other offline sources.

## Currently Supported APIs

- `/scrape/bus_scrapper` - Scrapes bus schedule or related transport information.
- `/scrape/notice_scrapper` - Scrapes notices from the KUET website.
- `/scrape/{dept}/faculty` - Scrapes faculty information for a specific department ({dept} is a placeholder for department code).
